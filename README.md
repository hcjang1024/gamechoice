# 한뉘 · 첫 번째 숨

한뉘 세계의 새 제자가 되어 이름, 숨의 길, 결과 무기 / 매개를 정하는 정적 웹 게임 시제품.

`dist/index.html`을 정적 HTTP 서버로 제공한다. 빌드와 의존성 설치는 필요 없다.

예: 이 폴더에서 `python -m http.server 4173 --directory dist` 실행 후 `http://localhost:4173` 접속.

게임 전용 추가 설정: 공동 수련처 여울원, 동료 이솔, 약초 배달 사건, 무기별 마법 매개 방식. 원작 소설 문서는 수정하지 않는다.

서장에는 길 체험과 불가역적 확정, 일곱 결, 여섯 무기, 세 번의 수련, 준비에 따른 실전 판정, 세 가지 결말, 첫 기술, 브라우저 자동 저장과 기록 내려받기가 있다. 전투의 부상은 서장 진행을 막지 않으며 이솔의 도움으로 다음 장면에 이어진다.

`node --test engine.test.mjs`로 선택 흐름을 검증한다.
