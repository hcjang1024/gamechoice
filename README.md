# 한뉘 · 첫 번째 숨

이름을 직접 정한 제자로 한뉘의 세계를 살아가는 삽화형 텍스트 RPG. 정지 일러스트와 선택에 따른 성장, 직접 행동을 고르는 턴제 전투를 제공한다.

## 실행

빌드나 의존성 설치 없이 `dist/`를 정적 HTTP 서버로 제공한다.

```sh
python -m http.server 4173 --directory dist
node --test *.test.mjs
```

`http://localhost:4173`에 접속한다. 자동 저장은 이 브라우저의 `hannui-first-breath-v1` 키를 사용한다. `.openai/hosting.json`은 기존 Sites ID와 정적 배포 경로를 유지한다.

## 화면과 직접 조작

사용자가 제공한 `sample/`과 `sample/Skills/` 이미지를 참고했다. 참고 자료는 로컬에 보존하고 Git 및 배포에서 제외한다. 기존 게임 삽화와 직접 작성한 SVG 아이콘을 사용한다. 검정·회색 바탕의 작은 카드, 선택 강조, 특별 능력의 파랑과 궁극기의 금색을 적용했다.

상단에 이름·직업·체력·숨·챕터와 엽전·강화석·성장점·약초를 고정 표시한다. 하단 여정·기술·장비·기록 탭과 초상화를 누르는 캐릭터 정보창을 제공한다. 기술은 4×4 카드로 표시하며 미습득 기술도 상세창에서 효과·계수·조건을 살펴볼 수 있다.

전투에는 적 정지 일러스트·체력·상태이상·준비 행동과 내 주요 능력치를 보여준다. 내 턴에 기본 공격·기본 방어·호흡 고르기 또는 장착한 기술을 선택한다. 턴을 쓰는 행동 후 적이 한 차례 반응하고 다시 내 선택을 기다린다. 먼저 움직이는 적의 선제 행동은 진입 시 처리한다. 기다리거나 다른 탭을 읽는 동안 전투는 진행되지 않는다. 자동 재생·재생 속도·결과 건너뛰기·캐릭터 이동 애니메이션은 플레이 화면에서 사용하지 않는다.

기술별 숨 소모·턴 단위 쿨타임·일부 기술의 전투당 사용 횟수·준비 완료 턴을 적용한다. 턴 소모 없는 보조 기술도 중복 사용을 제한한다. 기본 행동은 기술 봉쇄 중에도 가능하다. 공격·방어·반격·주문·회복 결과를 기록하며 모든 진행 상태와 난수가 저장된다. 새로고침으로 횟수나 결과를 되돌릴 수 없다. 전투 결과가 확정되면 최대 숨으로 회복하며 체력은 별도로 유지한다.

`playTurn()`과 `battleActions()`가 직접 조작 API다. `tickBattle()`과 `fastForward()`는 결정적 판정과 회귀 검증을 위한 내부 시뮬레이션으로 유지한다.

## 두 길과 직업별 열여섯 기술

무기 6종(맨손·검·도·창·활·지팡이) × 숨의 길 2종(쌓는 길·끌어 쓰는 길) × 속성 7종(물·불·흙·바람·나무·쇠·번개)의 **84개 조합**을 지원한다. 조합마다 공격 4·수비 4·특수 4·궁극기 4의 **16개**, 전체 **1,344개 기술 구성**이다. 플레이어에게는 자신의 조합에 맞는 16개만 표시한다. 무기 선택이 숨의 길을 제한하지 않는다.

| 유형 | 기술 후보 | 장착 |
| --- | --- | --- |
| 공격 | 무기 기술, 결의 기술, 연속격, 무기·결 합성 | 1개 |
| 수비 | 반격/교란, 기초 수비, 속성 반격/역류, 수호 결계 | 1개 |
| 특별 능력 | 호흡, 회복, 정화, 다음 공격 강화 | 1개 |
| 궁극기 | 첫 깨달음, 연쇄 합성, 상태 소모 일격, 운용 극의 | 1개 |

기술은 `techniques.mjs`의 무기별 고유 동작 96개, 속성별 유형·순번별 연계 112개, 길별 운용 32개를 합성해 생성한다. 기술 이름만 치환하지 않고, 각 조합에서 실제 효과 명세가 달라진다. 연타 수·관통·표식·파쇄·회피·반격은 무기에 따라, 즉시 발동·축기 소비와 주문 준비·공명 소비·영역은 길에 따라, 중첩 부여·소모·이전·회복·보호막 전환은 속성과 유형에 따라 달라진다. 같은 유형을 선택하면 해당 칸의 기술만 교체한다. 새 기술을 배울 때 기존 선택은 덮어쓰지 않는다. 이전 저장의 중복 장착은 유형별 첫 기술을 남기고 해제하되 습득·강화 기록은 유지한다.

처음에는 기본 행동만 사용하고, 기초 수련 뒤 첫 기술 하나를 고른다. 이후 깨달음·성장·가르침·일부 합성으로 하나씩 익힌다. 능력치만으로 자동 습득하지 않는다. 네 가지 합성 결과는 별도 이름을 가지며 재료 기술은 남는다.

쌓는 길은 기본 동작과 일부 보조 기술로 축기를 최대 3 모아 해당 자원을 소모하는 즉시 발동 무공에 방출한다. 기술별 축기당 타격 위력 +2~3 또는 보호막 +2다. 끌어 쓰는 길은 행동마다 주변 숨을 받아 공격 주문을 준비한 뒤 직접 발동한다. 준비 중 방어·호흡·보조 기술을 선택할 수 있다. 큰 강타나 감전으로 준비가 끊길 수 있으며 영역·교란·유지 회복으로 운영한다. 맨손의 속박, 검·창의 관통, 도의 파열, 활의 유도, 지팡이의 보호막 등 매개별 효과도 유지한다.

불은 자신의 화상을 적에게 이전하거나 소모해 위력·회복·보호막으로 전환한다. 물은 냉기 소비·정화·유지 회복, 흙은 부식·파쇄·보호막 소비, 바람은 명중·회피·표식, 나무는 중독 소비·흡수 회복, 쇠는 출혈·반격·출혈 소모, 번개는 감전·교란·표식을 연계한다. 표식은 최대 6중첩, 공명은 최대 3중첩이며 임시 능력 보정·유지 회복과 함께 저장된다. 기술의 고정 효과는 강화에 맞춰 상세창과 성장 미리보기에도 반영한다.

## 패시브·능력치·속성

패시브는 별도로 3개를 장착한다. 체력·숨·위력·방어·명중·기동의 기존 6개에 전투 시작 보호막, 세 행동마다 숨 회복, 기본 방어 시 회복의 조건부 패시브 3개를 추가했다. 장착한 기술만 적용되며 습득과 최대 +3 강화는 액티브와 별개다. 장비·패시브를 반복 장착해 현재 체력·숨을 복제할 수 없다.

제어는 방어와 숨의 위력, 숙련은 무기 위력·명중, 통찰은 명중·회피·치명타·속도에 영향을 준다. 스탯 설명은 상승 구간·상한을, 기술 설명은 실제 위력·보호막·회복 계산식을 표시하며 실제 전투와 공통 수식을 사용한다.

화상은 행동 시작 피해, 출혈은 공격 시 피해, 부식은 방어·보호막 약화, 중독은 공격·회복 약화, 냉기는 위력 약화, 흔들림은 명중 저하, 감전은 기술 봉쇄다. 같은 지속 피해로 통일하지 않으며 다음 전투로 이어지지 않는다.

## 성장·여정·장비

성장점이 생기면 보상부터 선택해야 한다. 기술·강화·패시브·능력치·아이템 전체 후보에서 가중치나 유형별 보장 없이 무작위 3개를 제시하고 하나를 선택한다. 같은 기술은 최대 +3 강화로 제시한다. 후보는 저장되어 새로고침으로 바뀌지 않는다. 다른 탭은 읽을 수 있지만 장착·사용은 배분 후 가능하다.

각 챕터는 9단계다. 1~3·5~7단계는 전투·이벤트·공방·상점 중 서로 다른 두 종류만 제시한다. 4·8단계는 고정 휴식, 9단계는 보스다. 갈림길에서는 종류만 알려주고 결과는 선택 후 보여준다. 반복 방문·무한 휴식·반복 보상으로 성장할 수 없다. 공방의 가르침은 등급·능력 조건에 맞는 3~5개를 제시하며 구입·재접속·합성실 왕복으로 바뀌거나 보충되지 않는다.

서장의 약초 배달과 끊어지는 다리 사건 뒤 첫 의뢰 「사라진 전령」, 두 번째 챕터 「청운문 아래, 끊어진 인장」으로 이어진다. 두 챕터 보스와 결말까지 플레이 가능하다. 챕터 이동은 성장·소지품을 유지하고, 재도전은 해당 챕터 시작 상태를 복원해 반복 보상을 막는다. 동료 이솔과의 관계는 능력치와 별개인 사건 기록이다.

장비 7종·소모품 6종에 일반·정제·희귀 등급을 적용해 39종이다. 등급 1/2/3부터 등장하며 상위 등급의 수치·가격·추가 효과가 달라진다. 구입·성장 보상·장비 화면에서 등급과 착용 부위를 표시한다. 장비 탭에서 손/매개·발·몸·장신구를 착용·해제하고 소모품을 사용한다. 장착 관리로 장소나 여정 단계가 바뀌지 않는다.

버전 1~6 저장과 이전 6단계 여정은 이름·학습·강화·소지품·현재 장소·전투 상태를 유지하며 이어진다. 현재 저장 버전은 6이다. 원작 소설 문서는 변경하지 않는다. 게임 전용 여울원·이솔·배달 사건과 청운문의 추적자·가짜 인장 사건은 별도 각색이다.

## 검증

자동 테스트는 기존 성장·상태이상·경제·여정·저장 회귀와 84개 조합의 1,344개 기술 구성·실제 발동, 유형별 교체, 직접 행동, 주문 준비와 방어 후 발동, 쿨타임·횟수·준비 턴, 무료 행동 중복 차단, 조건부 패시브, 정화·상태 소모와 저장 복원을 검사한다.

Edge 360/390/768/1440px에서 대기 중 전투 정지, 직접 공격, 적 삽화, 16개 카드와 상세창, 스탯 정보, 기술 교체, 장비, 주문 준비·방어·발동과 재접속을 확인했다. 두 길 모두 서장부터 두 번째 보스까지 실제 선택·보상·재화와 직접 조작 버튼만으로 완료했다. 고정 휴식·가르침·등급 장비와 전투 후 숨 회복도 확인했다.

새 안내 샘플 세 장의 전투 정보 확인 방식을 반영해 적 이름을 누르면 공격·방어·속도·보호막과 강타·주문·반격 주기를 볼 수 있다. 상태이상은 눌러 상세 설명을 확인한다. 샘플의 보석 수집·부활 횟수·능력 7레벨 진화·능력 9종 제한은 이번 기술 개편에 도입하지 않는다. 사용자 요청인 유형별 하나, 총 4개 장착을 우선한다.
