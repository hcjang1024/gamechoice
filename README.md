# 한뉘 · 첫 번째 숨

한뉘 세계의 새 제자가 되어 이름, 숨의 길, 결, 무기 / 매개를 정하는 삽화형 텍스트 RPG 시제품.

`dist/index.html`을 정적 HTTP 서버로 제공한다. 빌드와 의존성 설치는 필요 없다.

예: 이 폴더에서 `python -m http.server 4173 --directory dist` 실행 후 `http://localhost:4173` 접속.

게임 전용 추가 설정: 공동 수련처 여울원, 동료 이솔, 약초 배달 사건, 무기별 마법 매개 방식. 원작 소설 문서는 수정하지 않는다.

서장에는 길 체험과 불가역적 확정, 일곱 결, 여섯 무기, 세 번의 수련, 실제 턴별 자동 전투, 세 가지 결말, 첫 깨달음, 브라우저 자동 저장과 기록 내려받기가 있다. 전투의 부상은 서장 진행을 막지 않으며 이솔의 도움으로 다음 장면에 이어진다.

서장 이후에는 첫 의뢰 「사라진 전령」이 이어진다. 여울원을 거점으로 솔바람 산길 → 옛 취수로 → 안개 고갯길을 순서대로 개방한다. 빠른 적, 방어가 높은 적, 강한 공격 주기가 짧은 우두머리를 상대하며, 재탐험으로 실전 경험·엽전·강화석을 얻는다. 등급 상승의 성장점은 능력치 또는 기술 강화에 사용하며 도구·권갑과 방호구를 별도로 보강한다. 약초는 전투 준비에서 사용하고, 거점의 무료 휴식으로 체력과 숨을 모두 회복할 수 있다. 패배는 보상 없이 복귀하며 재도전 가능하다.

서장의 첫 깨달음은 고유 기술로 배운 기술 목록에 추가된다. 전투 보상은 전투당 한 번만 정산하고, 최초 단서와 약초는 지역당 한 번만 지급한다. 의뢰를 마친 뒤에도 지역 재탐험과 성장은 가능하다. 버전 1~3의 서장 및 탐험 저장은 버전 4로 이어지며, 소지품·장착·학습 기록을 추가한다.

전투 전에 배운 기술을 두 개까지 장착한다. 전투는 무기의 위력·방어·속도·사거리, 수련 능력치, 결, 남은 숨, 기술 재사용 대기에 따라 진행한다. 명중·회피·치명타는 저장 가능한 시드 난수로 판정하며, 빠른 진행과 턴별 재생, 중간 저장 복원은 같은 결과를 낸다. 일시 정지, 재생 속도, 빠른 진행을 지원한다. 전투 로그는 여정 기록에도 포함된다.

전투 무대는 매복꾼·방패병·우두머리와 제자의 전신 이미지를 표시한다. 실제 판정이 공격·기술·방어·흡수·회피·반격·회복·경직의 연출 사건을 내보내며, 이를 이동·피격·궤적·보호막·피해 수치로 재생한다. 사건 수에 맞춰 다음 행동까지 기다려 연출을 겹치지 않게 한다. 한 행동씩 진행하거나 직전 행동을 다시 볼 수 있으며, 다시 보기는 전투 상태를 변경하지 않는다. 우두머리는 반격 태세와 역습을 사용한다. 동작 줄이기 설정에서는 움직임을 줄이고 행동 이름을 표시한다.

상점은 장비 7종과 소모품 6종을 판매한다. 손/매개·몸·발·장신구 슬롯에 각각 하나씩 장착하며, 장비는 최대 자원·위력·방어·속도·명중·회피에 영향을 준다. 회복과 숨 회복 소모품, 다음 전투 한 번에 적용되는 위력·속도·보호막 준비품을 지원한다. 소지품은 거점과 전투 준비에서 사용할 수 있다.

수련소에서 기초 수비·집중 호흡·연속격·응급 조율을 배울 수 있다. 기술 조합실에서는 무기+결의 기술, 결+간파 반격, 기초 수비+결, 연속격+기존 조합 기술을 이어 새로운 기술 4종을 익힌다. 재료 기술은 유지하고 재화만 소모한다. 조합 결과는 전투 준비에서 장착해야 자동 전투에 사용된다.

동료 관계는 숫자 능력치와 분리된 사건 목록이다. 함께한 수련, 구조, 부상 등을 기억하고 이야기의 조건으로 사용한다. 이전 버전 저장은 이름과 진행을 보존하면서 관계를 사건으로 변환한다.

`dist/assets/`의 세 배경과 `dist/assets/combat/`의 전투 인물 4종은 내장 image_gen으로 제작했다. 정확한 프롬프트와 파일 매핑은 `image-prompts.json`에 있다. 제자의 뒷모습은 플레이어 캐릭터를 나타내는 공용 이미지이며 무기 표식은 선택한 무기에 따라 바뀐다.

`node --test engine.test.mjs journey.test.mjs workshop.test.mjs`로 84개 캐릭터 조합, 전투 자원, 기술, 관계, 저장 복원, 지역 개방, 보상 중복 방지, 강화 비용, 패배 후 복귀와 재도전, 장착 슬롯·소모품·조합 재료·자동 반격과 연출 사건을 검증한다. Edge 브라우저에서 데스크톱과 390px 모바일 크기의 전체 플레이, 적 이미지 로딩, 장착 제한, 자동 진행·일시 정지·속도·빠른 진행·한 행동 진행·직전 행동 다시 보기, 중간 저장 복원, 상점 필터·구입·장착·조합, 다운로드, 저장소 접근 불가 상황을 추가 검증했다. 첫 의뢰는 이전 서장 완료 저장에서 출발해 실제 보상과 강화만으로 우두머리를 격파하고 결말까지 이어짐을 확인했다.
