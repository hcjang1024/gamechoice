# 한뉘 · 첫 번째 숨

한뉘 세계의 새 제자가 되어 이름, 숨의 길, 결, 무기 / 매개를 정하는 삽화형 텍스트 RPG 시제품.

`dist/index.html`을 정적 HTTP 서버로 제공한다. 빌드와 의존성 설치는 필요 없다. 이 폴더에서 `python -m http.server 4173 --directory dist` 실행 후 `http://localhost:4173`에 접속한다.

게임 전용 추가 설정은 공동 수련처 여울원, 동료 이솔, 약초 배달 사건, 무기별 마법 매개 방식이다. 원작 소설 문서는 수정하지 않는다.

서장에는 길 체험과 불가역적 확정, 일곱 결, 여섯 무기, 세 번의 수련, 턴별 자동 전투, 세 가지 결말, 첫 깨달음이 있다. 브라우저 자동 저장과 기록 내려받기를 지원한다. 동료 관계는 능력치와 분리된 사건 기록이다.

서장 이후 첫 의뢰 「사라진 전령」은 **중간 선택 6회와 마지막 보스 1회**로 구성된다. 각 갈림길에서는 전투·상점·휴식·가르침·대장간·이야기 사건 중 제시되는 세 장소에서 하나만 고른다. 입장할 때 한 칸을 소모하며, 방문을 마치면 지나온 선택으로 돌아갈 수 없다. 소지품 장착은 자유롭다. 성장점이 생기면 배분 화면이 먼저 열리고, 모든 점수를 사용하기 전에는 갈림길·장비 관리·전투로 넘어갈 수 없다. 마지막 점수 사용 후 원래 장면으로 돌아간다. 전투 중이던 이전 저장도 배분 후 같은 행동 위치에서 이어지며 전투 준비 보너스를 유지한다. 휴식은 체력과 숨을 회복하지만 다른 성장 기회를 포기하는 선택이다.

일반 전투에서 패배하거나 포기해도 선택 횟수는 돌아오지 않는다. 전투와 사건 보상은 한 번만 지급한다. 보스는 여섯 선택을 모두 마쳐야 도전할 수 있으며, 승패가 결정되면 챕터가 끝난다. 재도전은 확인을 거쳐 챕터 시작 당시의 능력·기술·장비·재화·소지품을 복원하므로 반복 보상이 누적되지 않는다. 보스 준비 화면이나 무료 관리 메뉴를 오가도 전투 난수가 바뀌지 않는다.

새 제자는 기본 공격과 기본 방어만 사용한다. 세 번의 기초 수련 뒤 쌓는 길은 무기 기술·발경·간파 반격, 끌어 쓰는 길은 매개 투사술·영역 전개·흐름 교란 중 하나를 골라 배우고 자동 장착한다. 능력치만으로 기술이 자동 습득되지 않는다. 이후 깨달음·성장점·교관의 가르침으로 기술을 하나씩 선택한다. 장착은 두 칸까지이며 빈 칸이 있으면 새 기술을 자동 장착하고, 가득 차 있으면 교체 안내를 표시한다. 서장의 첫 깨달음은 고유 기술로 이어진다. 경험으로 얻은 성장점은 능력치나 기술에 배분하고, 대장간 방문 기회에 도구·권갑과 방호구를 보강한다. 버전 1~5의 저장은 버전 6으로 이어지며, 이름·성장·장비를 보존하고 기존 활동 기록으로 사용한 여정 횟수를 계산한다. 이전 저장의 배운 기술과 챕터 시작점도 보존한다. 완료한 의뢰는 완료 상태를 유지한다.

두 길은 실제 행동과 자원 운용이 다르다. 쌓는 길은 기본 공격·방어로 축기를 최대 3 쌓고, 기술 발동 시 축기를 모두 소모해 타격은 1당 추가 위력 2, 호신은 1당 보호막 1을 얻는다. 무공은 즉시 발동하며 반격은 실제 무기 타격이다. 기본 방어와 회복 호흡으로 내부 숨을 다시 모은다.

끌어 쓰는 길은 매 행동에 주변 숨 1이 유입되고, 공격 주문은 한 행동을 준비에 쓴 뒤 다음 자기 행동에 발동한다. 큰 강타(흡수 후 피해 3 이상)나 감전은 준비한 주문을 끊는다. 영역 주문은 적의 두 행동 동안 속성 상태를 다시 부여하고, 교란술은 물리 반격 대신 강타·반격 준비를 막는다. 회복은 세 행동의 유지 회복이며, 결계 조합은 보호막을 지속 보충한다. 맨손·검·도·창·활·지팡이는 두 길에서 모두 사용할 수 있고, 마법에서는 속박·방어 관통·파열·유도 명중·보호막 등 매개별 주문 효과가 적용된다. 첫 기술·교관 가르침·고유 기술·조합의 이름과 설명도 길에 맞게 표시한다. 선택한 길은 바꿀 수 없으며 이전 저장의 학습·장착·강화 기록은 해당 길의 새 효과로 이어진다.

전투 전에 배운 기술을 두 개까지 장착한다. 무기·능력치·결·남은 숨·재사용 대기에 따라 자동으로 싸운다. 저장 가능한 시드 난수로 명중·회피·치명타를 판정하며, 빠른 진행과 턴별 진행, 중간 저장 복원은 같은 결과를 낸다. 일시 정지·속도 조절·한 행동 진행·직전 행동 다시 보기를 지원한다. 실제 전투 판정으로 공격·기술·방어·흡수·회피·반격·회복·경직을 시각화하고, 동작 줄이기 설정을 지원한다.

상점은 장비 7종과 소모품 6종을 판매한다. 손/매개·몸·발·장신구 슬롯에 각각 하나씩 장착한다. 수련소에서 아직 배우지 않은 기본 기술과 추가 기술 4종을 배우고, 조합실에서는 재료 기술을 유지한 채 새로운 기술 4종을 익힌다. 조합 결과는 전투 전에 장착해야 자동 전투에 사용된다.

`dist/assets/`의 배경 3종과 `dist/assets/combat/`의 전투 인물 4종은 내장 image_gen으로 제작했다. 정확한 프롬프트와 파일 매핑은 `image-prompts.json`에 있다. 제자의 뒷모습은 플레이어 캐릭터 공용 이미지이며 무기 표식은 선택한 무기에 따라 바뀐다.

선택 화면과 전투 화면에서 제어·숙련·통찰·위력·방어·속도를 항상 표시한다. 전투 중 상태이상으로 변한 위력과 방어도 반영한다. 전체 기술, 장착 변경, 추가 가르침, 잠긴 조합, 전투 상세 기록은 접어서 제공한다. 갈림길 카드는 전투·상점·휴식 등 종류만 표시하며, 이야기 선택의 결과와 수치 보상은 선택한 뒤 알린다. 기술 설명과 상점 비용은 해당 관리 화면에서 확인할 수 있다. 상점은 소모품을 먼저 보여주며 장비와 전체 목록으로 전환할 수 있다. 전투는 적 모습과 양쪽 체력, 최근 행동을 항상 보여준다.

속성 기술은 물/냉기(위력 감소), 불/화상(행동 시작 피해), 흙/부식(방어 최대 2중첩 감소·보호막 소실), 바람/흔들림(명중 저하), 나무/중독(회복 절반·숨 회복과 위력 감소), 쇠/출혈(공격 시에만 피해), 번개/감전(다음 행동의 기술 봉쇄)을 부여한다. 적의 속성 강타도 플레이어에게 상태이상을 남긴다. 상태는 대상 행동 횟수로 만료되고 전투 간에는 이어지지 않는다. 배지에 남은 횟수와 중첩을 표시하고 누르면 효과 설명을 제공한다. 이전 연소 상태는 화상으로 변환한다.

`node --test engine.test.mjs journey.test.mjs workshop.test.mjs lessons.test.mjs progression-status.test.mjs paths.test.mjs`로 81개 테스트를 실행한다. 캐릭터 조합·전투·기술·관계·저장 복원과 함께 여정 한도, 재방문 차단, 방문 비용, 보상 중복 방지, 보스 잠금과 챕터 종료, 시작 상태 복원, 이전 저장 변환, 장비·소모품·기술 조합을 검증한다. Edge에서 실제 서장 저장으로 이어가기, 여섯 선택, 일반 전투와 상점·수련소·대장간 방문, 실제 자원만 사용한 보스 승리, 보스 패배와 재도전 확인, 중간 전투 재접속, 390px 모바일 화면을 확인했다. 새 학습 방식의 첫 선택·자동 장착·성장점 비용·기술 유지와 모바일 가독성도 검증했다. 두 길의 즉시 타격과 준비 주문, 축기와 방출, 시전 중단, 유지 영역, 교란, 유지 회복, 여섯 매개, 강화 효과, 조합 중복 표시 방지, 준비·유지 상태 저장 복원을 추가 검증한다. 두 길 모두 같은 서장 선택과 실제 보상만으로 보스를 격파하는 경로를 확인했다. 데스크톱과 390px 모바일에서 길 확정 전 안내·길별 첫 기술·교관·조합·축기 표시·주문 준비·영역·중간 재접속을 확인했다. 성장점 강제 배분·배분 중 재접속·사건과 보스 보상 후 복귀·기존 전투 재개·종류만 보이는 갈림길·일곱 상태이상 표시와 설명·실제 자원만으로 보스 승리를 브라우저에서 검증했다.
