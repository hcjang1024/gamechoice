# 한뉘 · 첫 번째 숨

한뉘 세계의 새 제자가 되어 이름, 숨의 길, 결, 무기 / 매개를 정하는 삽화형 텍스트 RPG 시제품.

`dist/index.html`을 정적 HTTP 서버로 제공한다. 빌드와 의존성 설치는 필요 없다.

예: 이 폴더에서 `python -m http.server 4173 --directory dist` 실행 후 `http://localhost:4173` 접속.

게임 전용 추가 설정: 공동 수련처 여울원, 동료 이솔, 약초 배달 사건, 무기별 마법 매개 방식. 원작 소설 문서는 수정하지 않는다.

서장에는 길 체험과 불가역적 확정, 일곱 결, 여섯 무기, 세 번의 수련, 실제 턴별 자동 전투, 세 가지 결말, 첫 깨달음, 브라우저 자동 저장과 기록 내려받기가 있다. 전투의 부상은 서장 진행을 막지 않으며 이솔의 도움으로 다음 장면에 이어진다.

전투 전에 배운 기술을 두 개까지 장착한다. 전투는 무기의 위력·방어·속도·사거리, 수련 능력치, 결, 남은 숨, 기술 재사용 대기에 따라 진행한다. 명중·회피·치명타는 저장 가능한 시드 난수로 판정하며, 빠른 진행과 턴별 재생, 중간 저장 복원은 같은 결과를 낸다. 일시 정지, 재생 속도, 빠른 진행을 지원한다. 전투 로그는 여정 기록에도 포함된다.

동료 관계는 숫자 능력치와 분리된 사건 목록이다. 함께한 수련, 구조, 부상 등을 기억하고 이야기의 조건으로 사용한다. 이전 버전 저장은 이름과 진행을 보존하면서 관계를 사건으로 변환한다.

`dist/assets/`의 세 장면은 내장 image_gen으로 제작했다. 정확한 프롬프트와 파일 매핑은 `image-prompts.json`에 있다. 인물 외모와 무기를 고정하지 않는 배경 중심 삽화이며, 수련처 / 샘 / 다리 장면에 맞춰 표시한다.

`node --test engine.test.mjs`로 84개 캐릭터 조합, 전투 자원, 기술, 관계, 저장 복원을 검증한다. Edge 브라우저에서 데스크톱과 390px 모바일 크기의 전체 플레이, 이미지 로딩, 장착 제한, 자동 진행·일시 정지·속도·빠른 진행, 중간 저장 복원, 다운로드, 저장소 접근 불가 상황을 추가 검증했다.
